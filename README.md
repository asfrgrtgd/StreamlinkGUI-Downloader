# StreamlinkGUI-Downloader

StreamlinkGUI-Downloaderは、YouTubeおよびTwitchの動画を簡単にダウンロードできるGUIアプリケーションです。

## 特徴

- YouTubeとTwitchの動画を
- ファイル名のカスタマイズ
- `mp4` および `ts` 形式での保存選択
- シンプルで使いやすいインターフェース

## 使用方法

1. `StreamlinkGUI-Downloader.exe` をダブルクリックしてアプリケーションを起動します。
2. ダウンロードしたい動画のURLを入力します。
3. 出力先ディレクトリを選択します。
4. 保存するファイル名を入力します（任意）。
5. 保存形式を選択します（YouTubeの場合は`mp4`のみ選択可能）。
6. 「ダウンロード開始」ボタンをクリックしてダウンロードを開始します。
7. ダウンロードの進行状況が表示され、完了後にファイルパスが表示されます。
